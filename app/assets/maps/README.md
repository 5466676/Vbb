# Painted map bases

Painted backgrounds for the map templates. Territory borders, owner colours, shields and
castles are drawn on top in code, clipped to the template's coastline.

| File | Template | Source |
|---|---|---|
| `fantasy-4p.jpg` | Fantasy continent, 4 players (1688×780) | AI-generated (Gemini) from the template's coastline; grey corners recoloured to sea |
| `real-world.jpg` | Real world (2048×1013) | AI-generated (Gemini) from `backend/maps/shapes/real-world.png`; coastline checked against the Natural Earth mask |
