# UI art

AI-generated (Figma image generation), picked by the owner from four options each
(design picker, round 1). Arabic text is never baked into images: titles are set in the app
with a real font on top.

| file | pick | notes |
|---|---|---|
| `../../branding/app_icon.png` | icon 3 (helmet on a glowing book) | 1024×1024 source for the launcher icons (kept out of the bundle) |
| `menu/menu_1.webp` … `menu_4.webp` | 2 first, then 1, 3, 4 | owner: use all of them; `menu_1` is the default, the app rotates the rest |
| `question_card.webp` | card 1 (parchment scroll) | background cut out (transparent) |
| `powerups/{remove_two,hint,shield,double}.webp` | set 4 (arrows, owl, shield, drum) | cut from one sheet with `tools/art/cutout_dark.py` |
| `victory.webp` | 2 (castle, flag and fireworks) | results screen for the winner |
